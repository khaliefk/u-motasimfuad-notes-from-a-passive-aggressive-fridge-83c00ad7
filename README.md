One funny passive-aggressive note a smart fridge leaves for its owner, written for the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7).

## The note

> The yogurt expired Tuesday. I kept it cold anyway, out of loyalty. You threw it out and called it spring cleaning. Noted.

## How it works

`main.py` writes that single line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). No network, no secrets, no dependencies, just the standard library.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
